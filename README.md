# Leonibel Segura Portfolio

Minimal portfolio for a full-stack developer focused on backend architecture, APIs, databases, and scalable products.

## Overview
This project is a personal portfolio built with Astro and Tailwind CSS, created to present:
- professional experience
- featured projects
- technical stack
- contact links

## Stack
- Astro
- Tailwind CSS
- TypeScript

## Local development
```bash
npm install
npm run dev
```

Then open:
```bash
http://localhost:4321
```

## Production build
```bash
npm run build
```
